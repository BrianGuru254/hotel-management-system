# Project Guidance

Before making changes in this repository, read all six files in `Documentation/context/`. They describe the HMS scope, current architecture, UI direction, code conventions, progress, and workflow.

Use the checked-in code and active configuration to determine what is implemented. Several design documents describe future work or older alternatives; do not treat those as current implementation facts. Preserve pre-existing working-tree changes and keep project context documents updated when meaningful decisions or progress change.
